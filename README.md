# Pirates game
This app help you calculates resources you need on the game. It's used to know how resources you'll need for a building.

- Calculate resources like food, wood, and silver how much costs
- To buy resources it's necessary to have gold
- After calculate return amount of gold of the purchase
- Inputs for three resources
- Help how resource it's necessary to level up
- Show all useful help
- Return all you need how many resources you need
- Show graphics and charts
- Heroes wins in versus in battle
